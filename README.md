# SISTEMA_GESTIÓN_EVENTOS_UNIVERSITARIOS
Proyecto: Gestión de Eventos Universitarios Contexto del Cliente La universidad realiza constantemente congresos, conferencias y capacitaciones. 

Problema:

• Inscripciones desorganizadas.  
• Control deficiente de asistencia.  
• Entrega manual de certificados.  

Necesidades del Cliente: 

• Gestionar inscripciones.  
• Controlar asistencia.  
• Emitir certificados.  
• Obtener estadísticas de participación.  

Restricciones: 

• Debe soportar al menos 1,000 participantes.
